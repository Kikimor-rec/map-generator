# Sci-Fi Map Generator

Интерактивный браузерный редактор 2D-планов космических кораблей, станций и баз для настольных ролевых игр (TTRPG).

## Текущий статус

Активная реализация использует grid-first генератор с детерминированным
best-of-N отбором, проверками TTRPG-проходимости, структуры корпуса и
эстетического качества. Корабли, станции и аванпосты получают разные силуэты и
разную грамматику основной циркуляции.

Статическая pressure topology v1 материализует внешние люки, шлюзовые камеры и
interlock-группы. Полный расчёт герметичных компонентов, runtime-разгерметизация
и атомарное перемещение комнат с перестройкой всех зависимых коридоров пока
остаются в работе. Авторитетный статус задач находится в
[плане разработки](docs/DEVELOPMENT_PLAN.md).

## 🚀 Возможности

### Редактор карт
- **Рисование комнат**: Создание прямоугольных помещений с привязкой к сетке
- **30+ типов помещений**: Мостик, инженерная, каюты, медотсек, лаборатория и др.
- **Система коридоров**: Рисование проходов между комнатами
- **Авто-роутинг**: Интеллектуальная прокладка коридоров вокруг препятствий
- **Двери**: Стандартные, шлюзовые, аварийные, защитные
- **Мультипалубность**: Поддержка нескольких уровней/палуб
- **Темы оформления**: Blueprint, Terminal, Clean Draft, Dark Metal, Sci-Fi Neon

### Процедурная генерация
- **8-этапный пайплайн генерации**: Полный цикл от параметров до готовой карты
- **3 архетипа**: Корабли, станции, аванпосты
- **Подтипы**: Исследователь, боевой, грузовой, научный и др.
- **Масштабируемость**: От 4 до 128+ комнат (размеры XS-XL)
- **Seed для воспроизводимости**: Одинаковый seed = одинаковый результат
- **Зональная планировка**: Командная, инженерная, жилая, грузовая зоны
- **Контроль качества**: Best-of-N выбор и hard gates для связности, корпуса, дверей и шлюзов
- **Полные внешние шлюзы**: Внешний люк, камера, внутренний люк и общая interlock-группа

### Система коридоров (расширенная)
- **Порты на комнатах**: Точки подключения коридоров (N/E/S/W)
- **Waypoints**: Ручное управление изгибами маршрута
- **Привязки и рероутинг**: Базовые anchors и preview готовы; полная атомарная перестройка при перемещении комнат в работе
- **Junctions**: T-образные и X-образные перекрёстки
- **Line Jumps**: Визуальные пересечения без соединения

## 🎮 Использование

### Создание комнат
1. Выберите инструмент **Room** на панели инструментов
2. Выберите тип комнаты в правой панели (Bridge, Engineering, и т.д.)
3. Зажмите ЛКМ и потяните для создания комнаты
4. Отпустите для завершения

### Рисование коридоров
1. Выберите инструмент **Corridor**
2. Кликните для начала коридора (привязка к стене комнаты)
3. Кликайте для добавления промежуточных точек
4. Двойной клик или Enter для завершения

### Процедурная генерация
1. Нажмите **Generate** в верхней панели
2. Выберите архетип (корабль/станция/аванпост)
3. Выберите подтип и размер
4. Нажмите **Генерировать**

### Навигация
- **Колесо мыши**: Zoom
- **ПКМ + перетаскивание**: Pan
- **Клик**: Выделение
- **Delete**: Удаление выделенного

## 🔧 API коридоров

### Типы портов
```typescript
interface Port {
  id: string
  roomId: string
  side: 'N' | 'E' | 'S' | 'W'
  mode: 'fixed' | 'sliding'
  position: number // 0-1
}
```

### Waypoints
```typescript
interface Waypoint {
  x: number
  y: number
  kind: 'locked' | 'auto'
}
```

### CorridorRouter
```typescript
const router = new CorridorRouter(rooms, corridors, {
  gridSize: 40,
  turnPenalty: 5,
  clearanceDefault: 1,
})

const result = router.route({
  from: startPoint,
  to: endPoint,
  widthClass: 'standard',
  intersectionPolicy: 'avoid',
})
```
