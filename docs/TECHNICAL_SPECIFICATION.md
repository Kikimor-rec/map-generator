# Техническое задание: 2D-редактор sci-fi карт

## Цель разработки

Создать удобный интерактивный инструмент, позволяющий ГМам и дизайнерам быстро генерировать и редактировать планы космических кораблей, станций и баз с реалистичной планировкой, поддерживающий богатую библиотеку sci-fi объектов, кастомизацию и экспорт для различных нужд.

## 1. Соединение комнат коридорами

## 1. Соединение комнат коридорами

### 1.1 Автоматическая стыковка и Роутинг
- **Алгоритм**: A* (A-Star) с пост-обработкой для ортогонализации путей.
- **Привязка**: Автоматическая привязка к стенам комнат (Snap to Wall).
- **Слияние**: Алгоритм `coalesce` для объединения накладывающихся коридоров в единые сегменты.

### 1.2 Инструмент "Коридор"
- **Режим рисования**: Click-to-click полилинии.
- **Ограничения**: Ортогональные сегменты (Horizontal/Vertical).
- **Валидация**: Проверка пересечений с комнатами (Collision Detection).

### 1.3 Порты и Waypoints
- **Порты**: Точки подключения на стенах комнат (Fixed/Sliding).
- **Waypoints**: 
  - *Locked*: Точки, поставленные пользователем (обязательные).
  - *Auto*: Промежуточные точки, созданные алгоритмом (могут меняться при пересчете).

### 1.4 Настраиваемые параметры (CorridorStyle)
- **WidthClass**: Narrow (20px), Standard (40px), Wide (60px).
- **Стены**: Отрисовка с учетом толщины и заливки.
- **Двери**: Авто-генерация дверей на стыке "Коридор-Комната".

### 1.5 Генерация переходников
- **Stub Generation**: Автоматическое создание "отростков" от портов перед началом маневрирования.
- **Junctions**: T-образные и X-образные пересечения (визуализация).

### 1.6 Визуальная обратная связь
- **Preview**: Предпросмотр пути в реальном времени при движении мыши.
- **Snapping**: Визуальные маркеры привязки к портам и углам.

## 5. Генерация случайных карт

## 5. Генерация случайных карт

### 5.1 Параметры генерации (GenerationRequest)
- **Archetype**: Ship / Station / Outpost (определяет общую структуру).
- **Subtype**: Explorer, Mining, Military, etc. (влияет на набор комнат).
- **SizeTier**: XS (4-8) ... XL (64-128+).
- **StyleProfile**: Utilitarian, Military, Luxury, Alien.
- **Loopiness**: 0.0 - 1.0 (Линейность vs Лабиринт).
- **Danger**: 0.0 - 1.0 (Вероятность ловушек/монстров).
- **Seed**: Строка для детерминированной генерации.

### 5.2 Пайплайн генерации (8 Stages)
1. **Initial**: Парсинг опций, инициализация RNG.
2. **Room Program**: Создание списка необходимых комнат по архетипу.
3. **Topology**: Построение абстрактного графа связей (Backbone, Loops).
4. **Layout Geometry**: Размещение комнат в пространстве (Grid-aligned force-directed).
5. **Corridor Routing**: Прокладка путей между комнатами (A* Router).
6. **Features**: Добавление дверей, шлюзов (частично).
7. **Cleanup**: Оптимизация, удаление недостижимых зон.
8. **Output**: Формирование JSON для редактора.

### 5.3 Логика планировки
- **Zoning**: Группировка по зонам (Command, Engineering, Crew, Cargo).
- **Anchors**: Мостик -> Nose/Top, Engineering -> Rear/Core.
- **Validation**: Проверка связности графа и достижимости всех комнат.

### 5.4 Quality Pipeline (Iterative)
- Генерация множества кандидатов (10-50).
- Оценка каждого кандидата по Scoring Function (компактность, связность, соответствие желаемой "петлистости").
- Выбор лучшего кандидата для отображения пользователю.
