# Техническое задание: 2D-редактор sci-fi карт

## Цель разработки

Создать удобный интерактивный инструмент, позволяющий ГМам и дизайнерам быстро генерировать и редактировать планы космических кораблей, станций и баз с реалистичной планировкой, поддерживающий богатую библиотеку sci-fi объектов, кастомизацию и экспорт для различных нужд.

---

## 1. Соединение комнат коридорами

### 1.1 Автоматическая стыковка
- При подтягивании коридора к стене комнаты — автоматическое создание проема (двери)
- Соединение геометрии коридора со стеной
- Естественный вид перехода (скругление углов, шлюзовые помещения)

### 1.2 Инструмент "Коридор"
- Отдельный режим для рисования коридоров как линий между точками
- Прямые сегменты и повороты под прямым углом
- Прокладка оптимального пути (кратчайший или ортогональный)

### 1.3 Плавные повороты и развилки
- Сглаженные четвертькруги или скошенные соединения
- T-образные и крестовые пересечения
- Объединение нескольких коридоров

### 1.4 Настраиваемые параметры коридора
- Ширина (узкий сервисный туннель / широкий ангарный проход)
- Тип стен (сплошная переборка, решетчатая и т.п.)
- Наличие дверей по концам
- Редактирование постфактум

### 1.5 Генерация переходников
- Автоматическое добавление переходных элементов при соединении разных типов комнат
- Воздушный шлюз между жилым модулем и внешним туннелем
- Лестничный узел при совмещении палуб на разных уровнях
- Шаблоны переходников из библиотеки

### 1.6 Визуальная обратная связь
- Направляющие при редактировании соединения
- Подсветка стены при наведении коридора
- Значок двери/проема на плане после создания

## 5. Генерация случайных карт

### 5.1 Параметры генерации
- **Размер**: количество комнат (4-100) или качественно (малый/средний/огромный)
- **Типы помещений**: галочки обязательных модулей
- **Соотношение**: % жилых, технических и др.
- **Количество палуб**: 1-N
- **Разветвлённость**: линейная / нелинейная / лабиринт
- **Seed**: для воспроизводимости

### 5.2 Алгоритм генерации

#### Этап 1: Генерация графа
- Создание узлов (комнат) нужных типов
- Построение остова (дерево) основных соединений
- Добавление циклов для нелинейности
- Соблюдение правил размещения типов

#### Этап 2: Геометрическое расположение
- BSP (Binary Space Partitioning) разбиение
- Учёт графа связности
- Минимизация длины коридоров
- Force-directed layout с привязкой к сетке

#### Этап 3: Пост-обработка
- Выравнивание по сетке
- Подгонка размеров по типу
- Прокладка коридоров
- Добавление переходников (шлюзы, лестницы)

### 5.3 Логика планировки
- Жилые группируются
- Реактор отделён, один основной туннель + аварийный выход
- Мостик спереди/сверху
- Ангары на внешней стороне

### 5.4 После генерации
- Полная редактируемость
- Возможность перегенерации части карты

## 12. Техническая реализация

### 12.1 Стек технологий
| Компонент | Технология | Версия |
|-----------|------------|--------|
| Сборка | Vite | 6.x |
| UI Framework | React | 18.x |
| Графика | PixiJS | 7.x |
| State Management | React Context + useReducer | — |
| Стили | Tailwind CSS | 3.x |
| Язык | TypeScript | 5.x |

### 12.2 Архитектура
```
src/
├── core/           # Типы, константы, утилиты
├── store/          # Управление состоянием
├── ui/             # React компоненты
│   ├── canvas/     # PixiJS канвас
│   ├── panels/     # Панели интерфейса
│   └── layout/     # Макет приложения
├── generators/     # Алгоритмы генерации
└── assets/         # Ресурсы
```

### 12.3 Форматы данных
- **Проект**: JSON с палубами, комнатами, коридорами
- **Пресеты**: JSON с геометрией и объектами
- **Экспорт**: PNG, PDF, JSON, UVTT

### 12.4 Производительность
- WebGL рендеринг (PixiJS)
- Culling (не рисовать за экраном)
- Оптимизация для 100+ комнат

### 12.5 UX требования
- Зум колесом мыши
- Панорамирование правой кнопкой / средней кнопкой
- Горячие клавиши (Del, Ctrl+Z, G, L)
- Undo/Redo
