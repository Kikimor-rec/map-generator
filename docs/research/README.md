# Research notes

Эта папка — для коротких исследований (алгоритмы, best practices, UI/UX patterns, performance, безопасность).
Цель: не “тащить блог-посты в код”, а переводить внешние идеи в наши требования и спеки.

## Naming
<topic>-YYYY-MM-DD.md

## Required structure
- Context (что в наших docs нельзя нарушать)
- Research question
- Sources (links)
- Findings (bullets)
- Decision (что берём/не берём и почему)
- Proposed changes (в какие docs/specs это вносится)
