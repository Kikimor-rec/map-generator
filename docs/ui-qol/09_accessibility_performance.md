# 09 — Доступность и производительность
Дата: 2025-12-17
## 9.1 Accessibility
- полнота управления с клавиатуры
- настраиваемые шорткаты
- UI scale
- high contrast theme
- reduced motion
## 9.2 Performance
- рендер по слоям с кэшированием
- simplified preview при drag
- генерация/роутинг в WebWorker
- ограничения на размер ассетов + предупреждения
## 9.3 Autosave и восстановление
- автосейв каждые N секунд
- crash recovery при перезагрузке вкладки
- snapshots (20–50), плюс именованные
