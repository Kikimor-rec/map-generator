# 03 — Горячие клавиши, командная палитра, ускорение работы
Дата: 2025-12-17
## 3.1 Базовые хоткеи
- Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z: undo/redo
- Space: pan
- V: select tool
- R: room tool
- C: corridor tool
- I: icon tool
- T: text tool
- Esc: cancel / exit tool / clear selection
- Delete: удалить выбранное
- Ctrl/Cmd+D: duplicate
- Ctrl/Cmd+G / Shift+Ctrl/Cmd+G: group/ungroup
- Ctrl/Cmd+K: command palette
## 3.2 Настраиваемые шорткаты (must-have)
- UI для ребинда всех команд.
- Профили:
  - “Default”
  - “Left-handed”
  - “Photoshop-like”
- Экспорт/импорт keymap (JSON).
## 3.3 Command Palette
- Поиск по командам и по объектам:

  - “Generate: reroll corridors”
- Поддержка “быстрых макросов” (опционально позже).
