# 12 — Панели, инспектор объектов и QOL микровзаимодействия

Дата: 2025-12-17

---

## 12.1 Inspector (properties panel)
Правый сайдбар (dock) показывает свойства:
- выбранного объекта (single selection),
- или “batch edit” для multi-selection (только общие свойства).

Требования:
- редактирование свойств не сбрасывает выделение
- изменения применяются сразу + поддерживают undo/redo
- быстрые пресеты стиля (цвет/толщина/углы) прямо в инспекторе

## 12.2 Верхняя панель (top bar)
Минимум:
- File: New / Open / Save / Export
- Undo / Redo (и шаги)
- Grid toggle + размер
- Snap toggle
- Layers button
- Generator button
- Help / Shortcuts

## 12.3 Левый тулбар (tools)
- Select
- Room
- Corridor
- Icon/Prop
- Text/Label
- Eraser (опционально, но удобно)
- Measure tool (очень полезно для TTRPG масштаба)

Требование: тулбар должен быть компактным и поддерживать “двойную панель” (для левшей — справа).

## 12.4 “Smart nudges” (клавиатурные сдвиги)
- стрелки: сдвиг на 1 unit
- Shift+стрелки: на 10 units
- Alt+стрелки: на 0.5 unit (если включены half-steps) — опционально

## 12.5 Tooltip подсказки и “first-run help”
- при первом заходе: короткий интерактивный туториал:
  - пан/зум
  - выбор/мультивыбор
  - построение коридора
  - генерация и выбор варианта
- hover tooltips для кнопок с указанием хоткея

## 12.6 “Non-destructive” микрофичи
- Lock/hide через маленькие иконки в object list
- “Solo layer” hotkey
- Быстрый “player export” (скрыть GM слои и экспортнуть)

## 12.7 Контекстные подсказки генератора
- если генератор выдал noPath для коридоров:
  - показать подсказку: “уменьшить clearance”, “добавить waypoint”, “разрешить line jumps”
