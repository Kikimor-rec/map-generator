# 04 — Библиотека ассетов, пресеты и модульность
Дата: 2025-12-17
## 4.1 Встроенная библиотека
Наборы:
- иконки комнат/функций (reactor, med, lab, cargo, airlock…)
- двери/шлюзы/люки (варианты)
- маркеры (опасность, радиация, биохазард, “запечатано”)
- мебель схематичная (кровати, терминалы, контейнеры)
- сети (вентиляция/кабели) отдельным набором
Требования:
- ассеты только с совместимыми лицензиями (free/open).
- метаданные лицензии: автор, источник, лицензия, ограничения.
## 4.2 Импорт пользовательских ассетов (хранятся на машине пользователя. Не забыть вставить об этом уведомление)
- SVG/PNG/WebP.
- Авто-миниатюры.
- Теги/поиск.
- “Favorites” и “Recent”.
## 4.3 Presets / Stamps / Modules
Виды пресетов:
- Room preset (комната + иконки + подпись)
- Corridor module (узел/развилка/шлюз)
- “Geomorph” (блок помещений + порты + правила соединения)
Функции:
- Создать пресет из выделения.
- Подключать пресеты по портам (snap).
- Версионирование пресетов (v1/v2).
## 4.4 Style presets
- Палитра (цвета помещений/коридоров/текста).
- Толщины линий.
- Corner style (sharp/rounded).
- Темы: “Blueprint”, “Terminal”, “NASA‑punk”.
