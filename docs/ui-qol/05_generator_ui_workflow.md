# 05 — UI генератора и Human‑in‑the‑loop рабочий процесс
Дата: 2025-12-17
## 5.1 Панель генерации
Секции:
- Profile: Realism / Futurism / Custom
- Scale: ship / station / outpost
- Room program: обязательные/опциональные комнаты + веса
- Topology: циклы/ветвления/chokepoints/тупики
- Decks: 1..N (опционально)
- Seed: поле + randomize
- Generate / Reroll:
  - Generate new
  - Reroll layout
  - Reroll dressing
  - Reroll corridors only
## 5.2 Галерея вариантов
- 6–12 миниатюр вариантов
- клик → применить
- pin для сравнения
- быстрый экспорт превью
## 5.3 Lock / Freeze
- Lock rooms
- Lock connections
- Lock style
- Lock deck assignment
## 5.4 Метрики TTRPG (видимые в UI)
- “Main loop present”
- chokepoints count
- dead ends count
- alt routes between key zones
- encounter pockets count
## 5.5 Генерация из модулей/геоморфов
- библиотека модулей слева
- constraints соединения
- сборка + ручная доводка
