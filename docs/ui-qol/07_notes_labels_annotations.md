# 07 — Ноты, подписи, аннотации и “GM Notes”
Дата: 2025-12-17
## 7.1 Labels
- Авто-лейблы комнат (имя, ID, размер).
- Режимы: minimal / full.
- Привязка к комнате (pin).
## 7.2 Room Notes
Для каждой комнаты:
- название
- назначение
- теги опасностей
- loot/clue/encounter
- player-visible флаг
## 7.3 GM Notes Editor
- rich-text (заголовки/списки/иконки)
- автоссылки на комнаты (roomId)
- экспорт в PDF/Markdown
- “player version” нотов
