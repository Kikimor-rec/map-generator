# 01 — Рабочее пространство и навигация
Дата: 2025-12-17
## 1.1 Canvas/Viewport
- Рендер: Canvas 2D (по умолчанию) + опционально SVG слой для текста/хит-тестов.
- Бесконечное поле с рабочими “границами карты” (page/bounds), которые можно включать/выключать.
- Фон: однотон/легкая текстура/прозрачный.
- Сетка: square/hex (опция), режим isometric view (опционально, как “вид”, не отдельная геометрия).
## 1.2 Панорама/зум
- Space+Drag или средняя кнопка: пан.
- Колесо: зум к курсору.
- Controls: zoom in/out, zoom to fit, zoom 100%, reset rotation (если появится).
- Миникарта (minimap) с прямоугольником view — включаемая.
## 1.3 Snap & Guides
Тумблеры в верхней панели:
- Snap to grid
- Snap to objects (узлы/порты/waypoints)
- “Magnet strength” (0..100) — мягкость прилипания
Guides:
- Направляющие (rulers), включаемые.
- Align/distribute команды (см. `02_layers_objects_selection.md`).
## 1.4 Быстрые режимы просмотра
- “Gameplay view”: скрыть UI-панели, оставить минимальные.
- “Print preview”: показать границы страниц, поля, масштаб.
- “VTT preview”: показать сетку/размер клетки/толщины стен/порты.
