# 00 — Обзор UX/QOL требований
Дата: 2025-12-17
## 0.1 Продуктовые принципы
- “Низкий порог — высокий потолок”: новичок делает рабочую схему за 5–10 минут, опытный — собирает библиотеку модулей/пресетов и генерирует варианты.
- “Авто делает скучное, пользователь делает важное”: авто-роутинг коридоров, авто-правила генерации, авто-выравнивание; вручную — смыслы и сценки.
- “Детерминированность”: seed + параметры + зафиксированные элементы → воспроизводимый результат.
- “Неразрушающее редактирование”: слои, история, версии, откат.
## 0.2 Целевые пользователи
- ГМы, которые хотят быстро получить playable схему для VTT/печати.
- Авторы модулей: которым важны экспорт/пакетирование и повторяемость.
- Игроки (опционально): просмотр/комментирование, если появится режим шаринга.
## 0.3 Что люди реально ценят в аналогичных инструментах (ориентиры)
- Быстрый браузерный флоу “без установки”, экспорт в картинку/PDF и совместимость с VTT.
- Печатные multi‑page PDF с реальным размером клетки/полями/разрешением.
- История действий (undo/redo) + простые настройки сетки/режимов.
- Пользовательские слои и кастомизация шорткатов как прямые QOL‑запросы.
- Экспорт/интеграция с VTT (универсальные форматы и импортеры).
